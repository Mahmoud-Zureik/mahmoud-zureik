نبذة عني

أنا مطور Frontend متخصص في تطوير مواقع الويب وبناء واجهات مستخدم حديثة، تفاعلية ومتجاوبة باستخدام HTML وCSS وJavaScript. أمتلك خبرة سنة في مجال تطوير الويب، وخلال هذه الفترة اكتسبت خبرة عملية من خلال بناء وتطوير العديد من المشاريع والتطبيقات. أهتم بكتابة أكواد منظمة وواضحة، وبناء واجهات سهلة الاستخدام ومتجاوبة مع مختلف أحجام الشاشات والأجهزة. لدي خبرة في التعامل مع JavaScript وDOM والأحداث (Events)

بالإضافة إلى استخدام Local Storage لحفظ وإدارة البيانات داخل تطبيقات الويب. أركز في عملي على تحويل الأفكار إلى تطبيقات ويب عملية ومنظمة، مع الاهتمام بالتفاصيل وجودة الكود وتجربة المستخدم. كما أواصل تطوير مهاراتي في JavaScript وFrontend Development من خلال التطبيق العملي وبناء المشاريع.

التخصص: Frontend Developer
الخبرة: سنة في تطوير الويب
التقنيات: HTML • CSS • JavaScript • DOM • Events • Local Storage
